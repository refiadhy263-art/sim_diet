# Panduan Operasi Database untuk SIM_DIET

## Keamanan Kritis: Penyaringan Bangsal

**Setiap query yang menyentuh data pasien atau staf HARUS disaring berdasarkan bangsal (`id_bangsal`).** Ini adalah mekanisme isolasi data utama. Data dari bangsal lain tidak boleh pernah bocor kepada pengguna yang login ke bangsal berbeda.

### Pola Query dengan Penyaringan Bangsal

```php
// ✅ BENAR: Saring berdasarkan bangsal
$id_bangsal = session('id_bangsal');
$patients = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->findAll();

// ❌ SALAH: Query semua bangsal
$patients = $this->pasien->findAll();

// ✅ BENAR: Dengan filter tambahan
$patients = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->where('status_rawat', 0)
    ->findAll();

// ✅ BENAR: Dalam metode model
public function getByWard($id_bangsal, $search = null) {
    $builder = $this->where('id_bangsal', $id_bangsal);
    if ($search) {
        $builder = $builder->like('nama_pasien', $search);
    }
    return $builder->findAll();
}
```

### Kapan TIDAK Menyaring berdasarkan Bangsal

- Pencarian sistem luas: tipe diet, bentuk diet (ini bukan khusus pasien)
- Autentikasi pengguna (tabel users tidak memiliki kolom bangsal)
- Admin melihat semua bangsal (jarang; implementasikan pemeriksaan izin eksplisit)

```php
// ✅ BENAR: Tipe diet bersifat sistem luas
$diets = $this->jenisDiet->findAll();

// ✅ BENAR: Pemeriksaan admin eksplisit
if (session('role') === 'admin') {
    $allPatients = $this->pasien->findAll();
} else {
    $id_bangsal = session('id_bangsal');
    $patients = $this->pasien->where('id_bangsal', $id_bangsal)->findAll();
}
```

## Metode Query Model

Semua model mengikuti struktur ini:

```php
<?php
namespace App\Models;

use CodeIgniter\Model;

class Pasien_model extends Model {
    protected $table = 'pasien';
    protected $primaryKey = 'id_pasien';
    protected $useTimestamps = true;           // Auto-manages created_at, updated_at
    protected $createdField = 'created_at';
    protected $updatedField = 'updated_at';
    protected $allowedFields = [
        'nama_pasien', 'id_bangsal', 'id_bed', 'id_jenis_diet',
        'bentuk_diet', 'status_rawat', 'tanggal_masuk', 'tanggal_keluar'
    ];

    // Metode standar dengan penyaringan bangsal
    public function getAll($search = null, $id_bangsal = null) {
        $builder = $this->where('id_bangsal', $id_bangsal);
        
        if ($search) {
            $builder = $builder->like('nama_pasien', $search);
        }
        
        return $builder->orderBy('tanggal_masuk', 'DESC')->findAll();
    }

    public function getIdPasien($id) {
        return $this->find($id);  // Mengembalikan catatan tunggal atau null
    }

    // Query khusus dengan hubungan
    public function getPasienWithDetails($id_bangsal) {
        return $this->select('pasien.*, jenis_diet.nama_jenis, bed.no_bed, bangsal.nama_bangsal')
            ->join('jenis_diet', 'jenis_diet.id_jenis_diet = pasien.id_jenis_diet', 'left')
            ->join('bed', 'bed.id_bed = pasien.id_bed', 'left')
            ->join('bangsal', 'bangsal.id_bangsal = pasien.id_bangsal')
            ->where('pasien.id_bangsal', $id_bangsal)
            ->findAll();
    }

    // Penghitungan dengan filter
    public function countByStatus($id_bangsal, $status) {
        return $this->where('id_bangsal', $id_bangsal)
            ->where('status_rawat', $status)
            ->countAllResults();
    }
}
```

## Pola Query Umum

### SELECT dengan WHERE

```php
// Single WHERE
$patient = $this->pasien
    ->where('id_pasien', $id)
    ->first();  // Mengembalikan baris pertama atau null

// Multiple WHERE (AND)
$patients = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->where('status_rawat', 0)
    ->findAll();

// WHERE IN
$patients = $this->pasien
    ->whereIn('id_bangsal', [1, 2, 3])
    ->findAll();

// WHERE NOT IN
$available_beds = $this->bed
    ->whereNotIn('status_bed', [1])  // 1 = ditempati
    ->findAll();
```

### LIKE / Pencarian

```php
// Like dengan wildcard
$patients = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->like('nama_pasien', $search)
    ->findAll();

// Case-insensitive (default di MySQL)
$patients = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->like('nama_pasien', $search, 'both')  // both = %search%
    ->findAll();
```

### JOIN (Hubungan)

```php
// LEFT JOIN dengan info diet
$patients = $this->select('pasien.*, jenis_diet.nama_jenis')
    ->join('jenis_diet', 'jenis_diet.id_jenis_diet = pasien.id_jenis_diet', 'left')
    ->where('pasien.id_bangsal', $id_bangsal)
    ->findAll();

// Multiple JOINs
$patients = $this->select('pasien.*, jenis_diet.nama_jenis, bed.no_bed')
    ->join('jenis_diet', 'jenis_diet.id_jenis_diet = pasien.id_jenis_diet', 'left')
    ->join('bed', 'bed.id_bed = pasien.id_bed', 'left')
    ->where('pasien.id_bangsal', $id_bangsal)
    ->findAll();
```

### ORDER BY & LIMIT

```php
// Order dan limit
$recent = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->orderBy('created_at', 'DESC')
    ->limit(10)
    ->findAll();

// Paginasi (offset)
$page = 1;
$per_page = 20;
$offset = ($page - 1) * $per_page;

$patients = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->limit($per_page, $offset)
    ->findAll();
```

### COUNT / AGGREGATE

```php
// Hitung semua
$total = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->countAllResults();

// Hitung dengan filter status
$active = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->where('status_rawat', 0)
    ->countAllResults();
```

## Operasi CRUD di Controller

### Buat (INSERT)

```php
public function save() {
    $rules = [
        'nama_pasien' => 'required|min_length[3]|max_length[100]',
        'id_bangsal' => 'required|numeric',
        'id_bed' => 'required|numeric',
        'id_jenis_diet' => 'required|numeric',
    ];
    
    if (!$this->validate($rules)) {
        return $this->response->setJSON([
            'status' => 'error',
            'message' => $this->validator->getErrors()
        ]);
    }
    
    $data = [
        'nama_pasien' => $this->request->getPost('nama_pasien'),
        'id_bangsal' => $this->request->getPost('id_bangsal'),
        'id_bed' => $this->request->getPost('id_bed'),
        'id_jenis_diet' => $this->request->getPost('id_jenis_diet'),
        'tanggal_masuk' => date('Y-m-d H:i:s'),
        'status_rawat' => 0,
    ];
    
    if ($this->pasien->insert($data)) {
        return $this->response->setJSON([
            'status' => 'success',
            'message' => 'Pasien berhasil ditambahkan',
            'id' => $this->pasien->getInsertID()
        ]);
    } else {
        return $this->response->setJSON([
            'status' => 'error',
            'message' => 'Gagal menambah pasien'
        ]);
    }
}
```

### Baca (SELECT)

```php
public function getData() {
    $id_bangsal = session('id_bangsal');
    $search = $this->request->getGet('search');
    
    $patients = $this->pasien->getAll($search, $id_bangsal);
    
    return $this->response->setJSON([
        'status' => 'success',
        'data' => $patients
    ]);
}

public function edit($id) {
    $id_bangsal = session('id_bangsal');
    $patient = $this->pasien->find($id);
    
    // Keamanan: Verifikasi pasien milik bangsal pengguna
    if (!$patient || $patient['id_bangsal'] != $id_bangsal) {
        return $this->response->setJSON([
            'status' => 'error',
            'message' => 'Pasien tidak ditemukan'
        ], 404);
    }
    
    return $this->response->setJSON([
        'status' => 'success',
        'data' => $patient
    ]);
}
```

### Perbarui (UPDATE)

```php
public function update($id) {
    $id_bangsal = session('id_bangsal');
    $patient = $this->pasien->find($id);
    
    // Keamanan: Verifikasi pasien milik bangsal pengguna
    if (!$patient || $patient['id_bangsal'] != $id_bangsal) {
        return $this->response->setJSON([
            'status' => 'error',
            'message' => 'Pasien tidak ditemukan'
        ], 404);
    }
    
    $rules = [
        'nama_pasien' => 'required|min_length[3]|max_length[100]',
        'id_jenis_diet' => 'required|numeric',
    ];
    
    if (!$this->validate($rules)) {
        return $this->response->setJSON([
            'status' => 'error',
            'message' => $this->validator->getErrors()
        ]);
    }
    
    $data = [
        'nama_pasien' => $this->request->getPost('nama_pasien'),
        'id_jenis_diet' => $this->request->getPost('id_jenis_diet'),
    ];
    
    if ($this->pasien->update($id, $data)) {
        return $this->response->setJSON([
            'status' => 'success',
            'message' => 'Pasien berhasil diperbarui'
        ]);
    } else {
        return $this->response->setJSON([
            'status' => 'error',
            'message' => 'Gagal memperbarui pasien'
        ]);
    }
}
```

## Hubungan Data

### Hubungan Kunci di SIM_DIET

```
users (id_users)
  ├─→ kategori_user (role)
  └─→ id_bangsal (penugasan bangsal)

pasien (id_pasien)
  ├─→ bangsal (id_bangsal) [WAJIB]
  ├─→ bed (id_bed) [OPSIONAL, dapat NULL]
  ├─→ jenis_diet (id_jenis_diet) [WAJIB]
  └─→ bentuk_diet (bentuk_diet) [OPSIONAL]

perawat (id_perawat)
  └─→ bangsal (id_bangsal) [WAJIB - penugasan bangsal]

gizi (id_gizi)
  └─→ bangsal (id_bangsal) [WAJIB - penugasan bangsal]

bed (id_bed)
  └─→ bangsal (id_bangsal) [WAJIB]
  └─→ status_bed: 0 = tersedia, 1 = ditempati
```

## Masalah Umum & Solusi

### Masalah: Query Mengembalikan Data Bangsal Salah

**Masalah:** Pengguna melihat pasien dari bangsal lain  
**Solusi:** Selalu saring berdasarkan `session('id_bangsal')`

```php
// ❌ SALAH
$patients = $this->pasien->where('status_rawat', 0)->findAll();

// ✅ BENAR
$id_bangsal = session('id_bangsal');
$patients = $this->pasien
    ->where('id_bangsal', $id_bangsal)
    ->where('status_rawat', 0)
    ->findAll();
```

### Masalah: Kunci Asing Constraint Gagal saat Hapus

**Masalah:** Tidak dapat menghapus bed karena pasien ditugaskan ke sana  
**Solusi:** Periksa catatan dependen sebelum menghapus

```php
public function delete($id) {
    $id_bangsal = session('id_bangsal');
    
    // Periksa apakah pasien mana pun menggunakan bed ini
    $count = $this->pasien
        ->where('id_bed', $id)
        ->countAllResults();
    
    if ($count > 0) {
        return $this->response->setJSON([
            'status' => 'error',
            'message' => 'Tidak dapat menghapus bed: ' . $count . ' pasien ditugaskan'
        ]);
    }
    
    $this->bed->delete($id);
    return $this->response->setJSON(['status' => 'success']);
}
```

### Masalah: Migrasi Gagal dengan Kesalahan Charset

**Masalah:** `SQLSTATE[HY000]: General error: 1709`  
**Solusi:** Pastikan charset database adalah UTF-8

```sql
ALTER DATABASE sim_diet CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Atau verifikasi di [Config/Database.php](Config/Database.php):
```php
'DBCollat' => 'utf8mb4_unicode_ci',
```

### Masalah: Bidang Timestamp Tidak Auto-Update

**Masalah:** `updated_at` tidak berubah pada update model  
**Solusi:** Pastikan model memiliki `useTimestamps = true`

```php
class Pasien_model extends Model {
    protected $useTimestamps = true;
    protected $createdField = 'created_at';
    protected $updatedField = 'updated_at';
}
```

## Tips Performa

- **Indeks kunci asing** untuk JOIN lebih cepat
- **Batasi hasil** saat mengambil semua catatan (gunakan paginasi)
- **Gunakan countAllResults()** alih-alih `count()` di PHP pada set hasil besar
- **Tembolok** daftar yang sering diakses (tipe diet, bentuk diet)
- **Eager load hubungan** jika memungkinkan (hindari N+1 query)

```php
// ❌ LAMBAT: N+1 queries
foreach ($patients as $patient) {
    $diet = $this->jenisDiet->find($patient['id_jenis_diet']);
}

// ✅ CEPAT: Single JOIN query
$patients = $this->select('pasien.*, jenis_diet.nama_jenis')
    ->join('jenis_diet', 'jenis_diet.id_jenis_diet = pasien.id_jenis_diet')
    ->where('id_bangsal', $id_bangsal)
    ->findAll();
```
